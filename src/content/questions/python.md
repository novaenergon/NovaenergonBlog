**Question:**  
What is Python, and why is it popular?  

**Answer:**  
Python is a high-level, interpreted programming language known for its easy-to-read syntax, versatility, and extensive libraries.  

Key reasons for its popularity:
- Easy to learn and use
- Strong community support
- Rich ecosystem of frameworks (e.g., Django, Flask, TensorFlow)
- Cross-domain usage (web dev, data science, ML, scripting)

**Quick Tip:**  
Practice writing small Python scripts daily to get comfortable with its syntax.
